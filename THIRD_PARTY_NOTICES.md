# Third-party notices

This file is the committed notice boundary for the storage-neutral workflow
bridge. The release dependency gate regenerates the module inventory and
requires a pinned, offline license-scanner receipt before accepting a release.

The bridge itself owns no external tool distribution, policy catalog, model,
document converter, renderer, or network transport. Notices for those
product-owned dependencies belong to their composing module, not this bridge.

At release time, retain the scanner report and the exact module inventory with
the local provenance bundle; do not copy source documents, prompts, or model
responses into this notice file.
